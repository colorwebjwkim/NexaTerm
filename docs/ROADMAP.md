# 구현 및 검증 상태

## 0.3 SFTP 실행 버전

- 같은 SSH 연결에 별도 SFTP 채널을 열어 로컬/원격 듀얼 패널과 터미널을 함께 표시한다. 경로 입력·상위 폴더·숨김 파일·새로고침·SFTP 재연결을 제공한다.
- 파일 및 폴더 재귀 업로드/다운로드, 다중 선택, 동시 작업 2개, 진행률/속도/개별 상태, 취소/재시도와 매번 묻기·건너뛰기·덮어쓰기·이름 변경을 구현했다. 폴더는 병합하고 내부 파일 충돌에 정책을 적용한다.
- 새 폴더·이름 변경·파일 및 빈 폴더 삭제, 원격 chmod(000~777). 비어 있지 않은 폴더 삭제는 지원하지 않는다.
- 전송 중 탭 닫기는 전송 유지/취소 후 닫기/닫기 취소를 제공하며, 유지한 연결은 마지막 전송 완료 후 정리한다.
- 로컬은 Windows 문서 폴더 또는 마지막으로 사용한 위치를 자동으로 열며, 네이티브 폴더 선택으로 기준 위치를 변경할 수 있다. 접근은 부여된 폴더 토큰 내부로 제한한다. 링크/정션 및 위험 파일명을 차단하고 폴더 전송은 깊이 64/항목 10,000개로 제한한다.
- russh-sftp 3.0.1의 바이너리 핸들 손실 문제를 로컬 패치했다. 네 바이트 바이너리 핸들을 사용하는 독립 Node ssh2 서버와 300파일 왕복 검증을 유지하여 문제를 회피하지 않았다.

Windows에서 Rust 테스트 9건과 실제 앱 E2E를 통과했다. 기존 프로필/DPAPI/SSH 테스트에 더해 SFTP 업로드/다운로드, 300개 파일 폴더 왕복 SHA-256 비교, 충돌 3종/취소/재시도, 경로 탈출/정션 차단, 폴더 생성·이름 변경·삭제 확인을 검증한다. 추가 스트레스 실행에서는 실제 1GiB(1,073,741,824바이트) 파일의 업로드·다운로드 SHA-256이 일치했으며 전송 중 터미널 입력, 중간 취소 시 미완료 대상 부재와 임시 파일 정리, 탭 종료 후 백그라운드 전송 완료를 확인했다.

1GiB 파일 SHA-256: `e18e3f358b46eae9266ac36a5ff6347f6bf09711dff389597f237d5fe83111d8`. 이 결과는 로컬 프로토콜 fixture의 실행 증거이며 외부 OpenSSH/Linux 서버·불안정 네트워크·다른 PC에서 동일 품질을 검증했다는 뜻은 아니다.

0.3 release 실행 파일 14,876,160바이트 및 NSIS 설치 파일 3,884,314바이트를 생성하고 release 실제 실행 스모크 테스트를 통과했다. 타입/Svelte 검사, ESLint/Prettier, Rust fmt/Clippy를 통과했다. 최종 검증 항목과 배포물 SHA-256은 [verification-0.3.json](../reports/verification-0.3.json), 의존성 감사는 [Cargo](../reports/cargo-audit-0.3.json) / [pnpm](../reports/pnpm-audit-0.3.json)에 보관한다. 설치/삭제와 상용 코드 서명은 아직 검증/적용하지 않았다.

## 이전 0.2 실행 버전

- Electron 제거, Rust + Tauri + Svelte 전환. Windows 실행 파일/NSIS 빌드 구성.
- SQLite 프로필 생성·수정·삭제, 그룹명·태그·즐겨찾기·검색.
- Windows DPAPI 비밀번호/passphrase 저장·변경·삭제·재사용. 저장된 값은 UI에 반환하지 않는다.
- 암호화 설정 백업, 선택적 비밀번호 포함, 네이티브 파일 선택, 복원 미리보기·병합·전체 교체.
- SSH 비밀번호/개인키 인증, 호스트키 최초 확인/저장/변경 시 재승인, 독립 탭, xterm 입출력/리사이즈, keepalive/접속 시간 초과/종료.
- 테마·폰트 크기·스크롤 버퍼 설정. Ctrl+T 프로필 생성, Ctrl+W 탭 닫기, Ctrl+Tab 탭 전환.

## 이전 0.2 검증 기록

Windows Rust 테스트 7건: DPAPI 왕복/오류, 재실행 후 자격 증명 복호화와 DB 평문 부재, 암호화 파일 백업·새 DB 재보호 복원·비밀번호 제외, 잘못된 암호/변조/형식 거부, 복원 트랜잭션 실패 시 기존 상태 유지, 병합 ID 충돌, 로컬 SSH 비밀번호/암호화 개인키 인증·독립 연결·한글 데이터·PTY 리사이즈·호스트키 변경 거부, 탐색/IPC origin 정책.

Windows WebView E2E: 실제 앱에서 프로필/암호화 비밀번호 저장 → 앱 재시작 → 저장된 비밀번호로 로컬 SSH 접속 → 지문 승인 → 같은 서버 2개 독립 탭 입출력 → 설정 저장. Rust SSH 테스트 외에 Node ssh2 테스트 서버와 상호운용을 확인한다. 백업 UI의 비밀번호 포함 기본 해제도 확인한다.

타입/Svelte 검사(오류·경고 0), ESLint, Prettier, Rust fmt/Clippy(-D warnings)를 통과했다. 최종 release 실행 파일(13,891,584바이트)과 NSIS 설치 파일(3,664,586바이트)을 생성했다. release 실제 실행 스모크 테스트에서 작업공간 표시, Rust IPC 응답 및 UI Node require 부재를 확인했다. 설치 프로그램은 생성 검증만 했으며 설치/삭제 검증은 아직 하지 않았다.

백업 파일 입출력과 복원은 Rust에서 실제 임시 파일/DB로 검증했다. 네이티브 파일 선택 대화상자의 전체 클릭 흐름, 별도 PC/Windows 계정에서의 복원, 외부 Linux 서버의 vim/top/sudo는 아직 검증하지 않았다. GitHub CI는 구성했으며 원격 실행 결과는 미확인이다.

## 남은 MVP 및 출시 작업

- SFTP 드래그 앤 드롭, 재귀 삭제의 별도 승인, 정렬/크기·수정 시간 비교 옵션, 전송 이력 영속화, Telnet, SSH Agent, keyboard-interactive/MFA, 점프호스트.
- RSA 호스트키/개인키 지원: 현재 비활성. CA 기반 SSH 호스트 인증서도 승인하지 않는다.
- 탭 이름 변경/정렬/고정, 터미널 검색, 상세 단축키 편집, 화면 배치 저장, 최근 접속 이력, 계층 그룹 트리.
- 외부 Linux SFTP 대형/다량 파일 및 다양한 SSH 서버/키 포맷 호환 검증, 네트워크 단절 복구, 장시간 성능/누수 검사.
- 설치/제거/업데이트 검증, 코드 서명, 라이선스 정책·상용 라이선스 검증 구현, 전체 의존성 라이선스 고지 및 출시 보안 리뷰.

현재 제품을 전체 MVP 완료 또는 상용 출시 승인 상태로 표시하지 않는다.
